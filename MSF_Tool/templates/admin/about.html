Systemübersicht

Das Multi-Source-Feedback-Tool (MSF) ist eine Anwendung, die dazu dient, Bewertungsabläufe für Auszubildende in Krankenhäusern zu automatisieren und auszuwerten.


Architektur

  • Framework: Python / Django
  • Datenbank: SQLite
  • Background Workers: Celery & Redis
  • Server Infrastruktur: Nginx & Gunicorn
  • Umfrage: Survey.js

Automatisierung

Das System nutzt Celery Beat, um täglich um 8:00 Uhr Cron-Jobs auszuführen. Es berechnet automatisch die Starttermine und löst E-Mail-Einladungen aus für:

  • Bewertung nach drei Monaten
  • Bewertung nach sechs Monaten
  • Tägliche Errinerung (bei ausstehenden Bewertungen)
